## Відповіді, знайдені в проєкті (а не запитані у власника)

У першій редакції плану тут стояли шість питань. П'ять із них проєкт уже
відповідає сам — питати їх означало не дочитати власні документи.

| Питання | Відповідь | Джерело |
|---|---|---|
| Тестові бази на проді | **Дропати всі.** Правило власника вже дано: «на проді не має бути баз, всі бази можуть бути на стадж або локально в докері». Інвентаризація: `campscout_test` 776 таблиць / 215 модулів (стара повна копія), `fayna_i18n_export` 198/24 (експорт перекладів), `fayna_test_run` 198/24 (прогін тестів), `campscout_prod` 114/11 (недобудована) — жодна не обслуговує прод | рішення власника 01.09 + `information_schema` кожної бази |
| Гілка `main` чи `17.0` | **`main`.** Це вимога ТЗ, не відкрите питання | `TZ:296` CI-04 |
| Формат комітів | **Conventional Commits.** ТЗ формату не задає; історія репо вже Conventional (`feat:`, `chore:`) — міняти без причини нема сенсу | `git log`, відсутність вимоги в ТЗ |
| Apps Store — чинний намір? | **Так.** «модуль на продаж», вимоги Apps Store у STD-02 і §2.6 ТЗ OWL | `TZ_OMNI_DASHBOARD_OWL:270, 262, 389` |
| Ліцензія | **LGPL-3 за ТЗ**, у маніфесті `OPL-1` — це порушення STD-01, а не вибір. Див. F-14 | `TZ:274` STD-01, `TEST_PLAN:390` T-64 |
| Docker на ноуті | **Не тримати піднятим.** Практичний висновок власника: 16 ГБ не вміщають Docker Desktop (3.4 ГБ) + VS Code (2.6 ГБ); Docker вішав машину 29.08. Тести ганяємо на staging-хості, локальний docker піднімаємо точково, з закритим VS Code | `project_macbook_docker_vm_thrashing_2026-08-29` |

### Лишається одне справжнє питання власника

**Ліцензія: правити маніфест під ТЗ (`OPL-1` → `LGPL-3`) чи правити ТЗ під маніфест?**
Це не технічне, а комерційне рішення: `price: 49` і `OPL-1` означають платний
пропрієтарний застосунок; `LGPL-3` дозволяє вільне поширення похідних.
ТЗ і код зараз суперечать одне одному, і сам я цю суперечність зняти не можу.

### Крок, який я не можу виконати технічно

`dropdb` зупиняє захисний класифікатор auto-mode. У `settings.json` це не заборонено
(`permissions.deny` — 7 правил, жодне не про бази; `Bash(docker exec *)` дозволено),
тобто блокує саме класифікатор, а не налаштування. Або власник виконує сам:

```
ssh campscout 'docker exec campscout_db dropdb -U odoo campscout_mig_test'
ssh campscout 'docker exec campscout_db dropdb -U odoo fayna_test_run'
ssh campscout 'docker exec campscout_db dropdb -U odoo campscout_test'
ssh campscout 'docker exec campscout_db dropdb -U odoo fayna_i18n_export'
ssh campscout 'docker exec campscout_db dropdb -U odoo campscout_prod'
```
